ЧАСТЬ A. ПОИСК через YouTube Data API v3
═══════════════════════════════════════

- Читай YOUTUBE_API_KEY из env
- GET https://www.googleapis.com/youtube/v3/search
  params: part=snippet, type=video, maxResults=25, q=query, key=YOUTUBE_API_KEY
- Собери треки в формате:
  {"id": videoId,
   "url": f"https://www.youtube.com/watch?v={videoId}",
   "title": snippet.title,
   "artist": snippet.channelTitle,
   "duration": None}
- Переименуй старую search_tracks → search_tracks_legacy (yt-dlp)
  Вызывай legacy как fallback, если API вернул [] или ошибку.
- Увеличь MAX_SEARCH_RESULTS с 10 до 25.
- Если YOUTUBE_API_KEY не задан — используй legacy и логируй warning.

ЧАСТЬ B. СКАЧИВАНИЕ через cobalt.tools
═══════════════════════════════════════

- Новая функция download_via_cobalt(video_url, output_dir) -> Path:
    POST https://api.cobalt.tools/api/json
    headers: {"Accept": "application/json", "Content-Type": "application/json"}
    json: {"url": video_url, "isAudioOnly": true, "aFormat": "mp3"}
    Из ответа возьми поле "url" → скачай через requests.get(stream=True)
    в output_dir/track.mp3
    Проверь размер файла (не больше MAX_TELEGRAM_UPLOAD_BYTES)
- Замени в download_mp3 вызов yt_dlp.YoutubeDL на download_via_cobalt.
  Но если cobalt упал с ошибкой — fallback на старую yt-dlp логику
  (переименуй её в download_mp3_legacy).
- Убери из download_mp3 опции format, postprocessors, extractor_args —
  они не нужны для cobalt.
- Для TikTok/Instagram в download_social_video_and_mp3 — используй cobalt
  с {"url": url, "isAudioOnly": false, "vQuality": "720"}.
  Fallback на yt-dlp если cobalt упал.

ЧАСТЬ C. НОВАЯ ФУНКЦИЯ: "Самые скачиваемые"

Нужно считать статистику скачиваний и показывать топ-10 в отдельном меню.

1) Новая таблица в SQLite (создать в initialize_playlist_database):

    CREATE TABLE IF NOT EXISTS download_stats (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        artist TEXT NOT NULL,
        source_url TEXT,
        count INTEGER NOT NULL DEFAULT 0,
        last_downloaded_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
        UNIQUE (title, artist)
    );
    CREATE INDEX IF NOT EXISTS idx_download_stats_count
        ON download_stats (count DESC);

2) Функция register_download(title, artist, source_url):
   - INSERT OR IGNORE по (title, artist), count=0
   - UPDATE count = count + 1, last_downloaded_at = CURRENT_TIMESTAMP
   - Вызывать в _send_downloaded_track_worker ПОСЛЕ успешной отправки аудио
     (там, где сейчас вызывается register_sent_audio)
   - Также вызывать в _send_social_video_and_audio_worker после успешной
     отправки аудио

3) Функция get_top_downloads(limit=10) -> list[dict]:
   SELECT title, artist, count, source_url
   FROM download_stats
   ORDER BY count DESC, last_downloaded_at DESC
